# 快捷启动 (QuickLaunch)

一个 iOS 越狱插件：保留 Dynamic Stage 的触发方式与触发面板，去掉分屏功能，直接变成**快捷打开 App** 的启动面板。

- 在屏幕底部指定区域上滑（或长按）唤出面板
- 面板内含：搜索、最近使用、已固定、全部应用，点一下直接打开对应 App
- 支持浅色 / 深色 / 跟随系统外观，图标 2~4 列可选

> 触发区域是插件自己实现的（原插件的私有系统手势无法直接复用），底部触发条会接管该区域触摸。

## 构建

```sh
sh build.sh roothide   # 隐根包
sh build.sh rootless
sh build.sh all
```

推送 `main` 分支或手动触发 GitHub Actions 会自动编译并发布 Release（当前矩阵只开 roothide）。

## 使用

1. 安装 deb 后进入「设置 → 快捷启动」
2. 打开「启用插件」
3. 「选择固定应用」里挑选想快速打开的 App
4. 按所选触发方式唤出面板即可点开 App
